# Celestial Cursors

A modern X-cursor theme based on [WhiteSur-cursors](https://github.com/vinceliuice/WhiteSur-cursors), designed to complement all Celestial GTK theme variants.

## Overview

Celestial is a single, unified cursor theme that works beautifully with all four Celestial color variants (Sea, Aliz, Azul, Pueril) in both light and dark modes. The cursors feature a clean, modern design with subtle styling that maintains visual consistency across your entire desktop.

## Design Philosophy

- **Universal Compatibility** - One cursor theme that looks great with all Celestial variants
- **Modern Design** - Clean, professional aesthetic
- **Professional** - Subtle and unobtrusive, suitable for work environments
- **High-DPI Support** - Multiple resolutions for crisp rendering on all displays

## Installation

### Using the Main Installer (Recommended)

The cursor theme is pre-built and ready to install using the main Celestial installer:

```bash
# Install cursors
./install.sh --cursors
```

Cursors will be installed to:

- **User installation (default):** `~/.local/share/icons/Celestial/`
- **System-wide installation (with sudo):** `/usr/share/icons/Celestial/`

### Applying the Cursor Theme

After installation, select **Celestial** in your desktop environment's cursor settings:

- **GNOME**: Settings > Mouse & Touchpad > Cursor
- **Xfce**: Settings > Mouse and Touchpad > Theme
- **KDE Plasma**: System Settings > Cursors
- **Cinnamon**: System Settings > Themes > Mouse Pointer
- **MATE**: System > Preferences > Look and Feel > Appearance > Theme > Customize > Pointer

### Uninstalling

Remove the cursor theme:

```bash
./install.sh --cursors -r
```

## Building from Source

The cursor theme is pre-built and included in the repository. However, if you modify the SVG source files or want to rebuild the cursors, you can use the build script.

### Prerequisites

Building cursors requires the following tools:

- `xcursorgen` - X11 cursor compiler
- `rsvg-convert` (librsvg2) - SVG to PNG converter
- `python3` - For SVG cursor generation (optional, for Wayland support)
- `git` - For cloning svg-cursor tool (optional, for Wayland support)

**Install on Fedora/RHEL:**

```bash
sudo dnf install xorg-x11-apps librsvg2-tools python3 git
```

**Install on Ubuntu/Debian:**

```bash
sudo apt install x11-apps librsvg2-bin python3 git
```

**Install on Arch Linux:**

```bash
sudo pacman -S xorg-xcursorgen librsvg python git
```

### Build Process

Run the build script from the cursors directory:

```bash
cd src/cursors
./build.sh
```

This will:

1. Generate PNG files from SVG sources at multiple DPI scales (x1, x1.25, x1.5, x2)
2. Compile binary cursor files using `xcursorgen`
3. Create symbolic links for cursor name aliases
4. Generate an `index.theme` file
5. Optionally generate SVG cursors for Wayland support
6. Output compiled cursors to `dist/` directory

## Project Structure

```
src/cursors/
|-- src/
|   |-- svg/             # SVG source files for all cursor states
|   |-- config/          # Cursor configuration files (hotspots, animation)
|   `-- cursorList       # Symbolic link aliases for compatibility
|-- dist/                # Compiled cursor theme (generated by build.sh)
|-- build.sh             # Build script (generates cursors from SVG)
|-- README.md            # This file
```

## Customization

To customize the cursor design:

1. **Edit SVG files** in the `src/svg/` directory
   - Modify colors, shapes, or styling
   - Maintain consistent dimensions and design language

2. **Adjust hotspots** in `src/config/*.cursor` files
   - Each file defines the cursor's click point (hotspot)
   - Format: `size x-hotspot y-hotspot path/to/image.png delay`

3. **Rebuild** the cursor theme:

   ```bash
   ./build.sh
   ```

4. **Install** the rebuilt cursors:

   ```bash
   cd ../..
   ./install.sh --cursors
   ```

## Cursor States

Celestial Cursors includes all standard cursor states:

- **default** - Standard pointer
- **pointer** / **hand** - Link/clickable element
- **text** / **xterm** - Text selection (I-beam)
- **wait** / **watch** - Busy/loading
- **crosshair** - Precision selection
- **move** - Move/drag
- **grab** / **grabbing** - Drag and drop
- **not-allowed** - Prohibited action
- **context-menu** - Context menu
- **help** - Help/question
- **progress** - Background task running
- **cell** - Spreadsheet cell selection
- **vertical-text** - Vertical text selection
- **copy** / **alias** - Copy/create alias
- **no-drop** - Invalid drop target
- **zoom-in** / **zoom-out** - Zoom controls
- **resize** - All resize directions (n, s, e, w, ne, nw, se, sw, ns, ew, nesw, nwse)
