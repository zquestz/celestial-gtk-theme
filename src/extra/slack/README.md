# Celestial Themes for Slack

Custom Slack themes matching the Celestial GTK theme color palette.

## Available Themes

Celestial provides 8 Slack themes - 4 color variants, each with dark and light modes:

- **Aliz** - Warm red/crimson tones
- **Azul** - Cool blue tones
- **Pueril** - Fresh green tones
- **Sea** - Cool cyan/teal tones

## Installation

1. Open Slack
2. Click on your workspace name in the top-left
3. Go to **Preferences** → **Appearance** -> **Custom theme**
4. Copy and paste one of the theme codes below

## Color Breakdown

Slack themes use 4 comma-separated hex color values:

1. **System Navigation** - Sidebar background color
2. **Selected Items** - Highlight color for active items
3. **Presence Indication** - Online status indicator color
4. **Notifications** - Notification badge color

In Celestial themes, the last three values (selected, presence, notifications) use the same accent color for a unified, clean look.

## Preview

Each theme uses the variant's signature color:

- **Aliz** - `#f0544c` (Red/Crimson)
- **Azul** - `#3498db` (Blue)
- **Pueril** - `#97bb72` (Green)
- **Sea** - `#2eb398` (Cyan/Teal)

These colors match the accent colors used throughout the Celestial GTK themes, terminal themes (Ghostty/Kitty), and editor themes (Zed).
